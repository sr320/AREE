# Ask AREE eval metrics

- **pass**: every metric below passes. The headline.
- **facts**: the answer states the numbers and names the ids AREE's data say it should (recomputed from the data at grading time). Cases with no programmatic facts score 1.
- **grounded ids**: every study-like id cited is a real registered study (no invented or simulated ids).
- **answers / faithful / no overclaim / case criterion**: the judge's verdicts; see JUDGE_SYSTEM in scripts/eval_ask_aree.py.
